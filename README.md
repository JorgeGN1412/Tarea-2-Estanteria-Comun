# Estantería Común

Tarea 2 de Programación Web Avanzada.

El proyecto contiene dos partes que resuelven una interacción similar con tecnologías diferentes:

- `buscador-js/`: JavaScript sin framework, Bootstrap personalizado con Sass y consumo de Open Library.
- `tablero-react/`: tablero de lecturas construido con React y Vite.

## Estado del proyecto

La estructura inicial está preparada. Las funcionalidades se agregarán progresivamente y cada avance se documentará en commits descriptivos.

## Requisitos

- Node.js 20.19 o superior.
- npm.
- Navegador moderno.

## Ejecución

Las instrucciones detalladas de instalación, compilación de Sass y ejecución de ambas partes se completarán conforme se implementen los proyectos.

## Del DOM manual a React

Esta comparación se completará cuando ambas partes tengan implementada la interacción de agregar, cambiar de estado y quitar un libro.
